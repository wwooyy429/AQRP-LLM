# 通用因子研究章程

目标是得到可解释、可复现、在未用于研究决策的数据上具有扣费后增量价值的因子。当前没有已登记候选、已选模型或已冻结交易规则。

研究按经济假设、FactorSpec、公式与时序审计、Research、LEAN回测、结果分析的顺序推进。每个假设必须说明机制、预期方向、期限、适用环境和失效条件；所有市场指标来自实际工具计算，合成检查只作为工程证据。

字段和算子由每个FactorSpec限定。特征只访问当时已可用的数据，标签匹配实际开平仓，财务按公开、供应商送达和摄入时刻连接。股票池和财务覆盖均须进行历史时点审计，不用今天的名单、不回填未来报告。

先固定模型研究因子，再固定因子研究模型。年度重估只更新冻结程序声明的可训练参数，并保留每个拟合版本的窗口、截止时点和哈希。更换经济逻辑、方向、参数范围、预处理、模型族、超参数或交易规则属于新配置。

采用config/research.json的六轮固定8年加1年滚动程序。开发选择只能用训练和开发验证结果。最终区间2024至2026年10月23日由独立执行器管理；完整区间含先前研究暴露，不能认证为未触碰独立测试。不得通过删除文件或换名称去掉这个标记。

新实验必须登记全部成功、失败、修复和取消记录。提交前占用预算，失败不返还。候选须检查与已有登记因子的结构相似度、绝对相关及固定模型下的组合增量；初始新登记库为空不代表以前的研究从未发生。

交易前明确成本、成交、流动性参与和风险规则，核对Research和LEAN计算与时序一致性并报告压力测试。缺少规范或证据时停止相应执行阶段，不用默认零成本、理想成交或空策略替代。

异步提交和编译成功都不等于回测完成。等待平台实际终态，不重复提交状态不明的任务。达到预登记拒绝或预算条件即结束；证据不足如实报告。

用户本次明确要求删除旧因子设置、文件和云端历史回测，故旧具体材料被清理。本章程要求保留今后的完整记录；既往只保留累计预算和必要的数据暴露事实，不再保留旧因子公式、参数或绩效。
