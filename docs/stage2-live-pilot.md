## 联合计划

现有独立EngineeringTask与CollectionTask各占一个配置，且LEAN依赖同一EngineeringTask的Research。为在剩余门槛内形成完整、预登记的工程试验，新增schema_version=2联合计划：一个父配置、一次Research执行，依次运行原2018年AAPL/MSFT原始行情缓存检查和固定40日全市场快照观察；之后同一父计划最多派发一次零订单LEAN。子观察不会另行注册配置或获得额外执行额度；一次Research调用中任何异常均消耗该次预扣，不能修改参数后免费重跑。

联合模板在`config/engineering_joint_pilot.json`，默认不启用。v1计划的字段、哈希、已扣费attempt和原回执恢复保留；v2明确绑定父源代码、子采集计划、字段目录、数据版本和报告身份。新配置注册与新执行均在同一权威Registry校验上限和项目占用。预览不登记、不扣费：

```powershell
python -B tools/research.py build
python -B tools/stage2.py preview --plan-file config/engineering_joint_pilot.json --projects-file audit/stage2_live_project_listing.json
```

父Research保留2018年两股原始OHLCV、交易所预期日历、缓存只读重放、最终日期拒绝和永久SID检查。子观察范围固定美东`[2018-01-01,2018-02-10)`，每日请求、每批1000、每窗上限50000；只取DollarVolume、HasFundamentalData、Time、EndTime四项观察字段，不用财务覆盖过滤原生返回成员。真实行及逐行衍生值只存QuantConnect Object Store；回执仅含严格登记的计数、缺失数、哈希和引用。缓存重放新增取数须为0；未知异常保留意图并停止，不伪装成缺失数据。

成功Research须包含与本父计划和attempt绑定的子观察摘要，随后LEAN仍须使用本Research已验证的SID与数据引用。提交成功、编译成功和运行完成分别记录。新回测提交后等待自动完成通知，不能轮询；终态核对使用实际原生结果与完整工程日志分块。

## 认证范围与缺口

40日观察用于检验历史快照、来源投影及缓存；不能自动认证2010–2023全历史US200。四字段未提供完整历史上市／分类证据，亦未执行合格的全样本20日排名审计，因此不能宣称取得了合格研究股票池。缺财务不会换成第201名，也不会用当前成分回填历史。行情与公司行动按同SID核对，未实际观察到的拆股、退市或改名继续未认证。

[QuantConnect基本面迁移说明](https://www.quantconnect.com/docs/v2/writing-algorithms/universes/equity/morningstar-migration)指出整段历史由新供应商数据流重建，部分旧属性虽能编译，读取会抛异常。文档列出10月10日master切换、10月31日旧数据弃用；其他概览的日期口径不能替代实际项目版本证据。本轮将取得的引擎版本、内容哈希和运行环境分别记录，供应商历史修订及分支未知仍保留。子观察暂不请求易受迁移影响的旧财报路径；这项明确受限设计不是财务数据认证。

报表期末、近似FileDate、UniverseHistory模拟时钟及当前摄入时间，均不能证明过去的实际公开／供应商送达／历史摄入时间。现有来源无法单独认证全部历史财务版本，相关标志维持false；正式研究不能因接口成功而开启。若本轮实际执行只能取得限定观察证据，结论必须是范围内通过、完整认证证据不足。

原生失败回执必须来自实际失败的工具执行；成功cell内捕获的预期异常只证明拒绝检查。已找到的早期失败摘要不足以重建原生错误封装。不能为了凑证据把失败摘要包装成真实回执，也不能故意耗尽最后Research槽后免费补跑。该缺口须依据实际交付的旧任务失败、可核验历史原件或后续明确授权的执行计划解决。

本轮新增v2是开发候选，须对固定源码独立审核；开发测试不授予阶段2验收。2024–2025既有暴露、2026独立性未知及数值精度限制保留，正式因子研究、最终测试、自动模型调用与交易关闭。
