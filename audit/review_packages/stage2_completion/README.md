## 失败、修正及原件

research-failure保留旧a6同最终测试的24方法未通过输出；1 failure和64 error是子例结果，缺新接口/协议，不是64个实际云端故障。首候选的Registry.ambiguous调用参数错误为合成夹具错误。root随后发现CWD依赖，固定入口改为清缓存后查唯一部署package位置、按部署root单读输入；异CWD和不明确root已覆盖。新entry-protocol只在首次prepare写，旧admitted恢复绝不补标记。一次派发许可在跨进程锁内消费，未知结果不授权重跑。原生失败语法仍仅有合成nbformat样例，尚无真实失败cell原件。

worker-identity默认schema1保持，实际_context显式开启schema2；同次拒绝读取得到格式/导入/路径指纹且消息限2048字节。严格提取器只输出白名单metadata，不授予远端来源。基线仅缺新module产生1 loader error，不能称25个旧bug。新受控诊断也不能追认旧75worker的实际差异。

certification保留零计数schema修补、两处已知答案时序修正、兼容测试辅助脚本导入错误及修复。额外peer发现的两个真实软件边界已修：空counts/refs加自由true不能通过分区汇总；已知老候选缺20日窗口记录不能被第201名补位掩盖。汇总现在必须提供calendar并通过hash绑定context重新核对私有原始输入。旧peer前源码按记录patch精确重建并验证原指纹，明确不是当时另外保存的源码原件。

peer-certification的首次36执行包含14额外方法及22被导入的重复仓库方法；当时probe.py被另一开发侧探针覆盖，不能将当前该文件冒称原执行字节。保留首次输出和这一来源缺口，随后使用独有native_agent_additional_probe.py固定前后hash、显式加载14方法重放。peer-certification-worker为另一组独立9方法探针，已分目录，避免再覆盖。汇总读取StopIteration等辅助错误同样保留。合成store、baseline/source75完整目录未再复制，按固定Git及脚本在隔离环境重建；不要对真实账本执行测试回放。
